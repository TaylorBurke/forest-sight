Forest Sight · Roadless Rule

What could happen to America's roadless forests if the Roadless Rule ends?

Since 2001, a national rule has barred new roads and most logging in the wildest parts of our national forests. In August 2026 the Forest Service proposed rescinding it. This project uses public data to show what is at stake, region by region, and what could change over the next 5 and 10 years.

How to read this project

  • It is a proposal. The Forest Service has proposed ending the national rule. The rule is still in effect until a final decision.
  • Scenarios are what-ifs. Nobody can say how much would be built, so each region shows low, mid and high cases and labels every assumption.
  • Every number is traceable. The data, code and methods are open source, so anyone can check the work or add a region.
Code, data pipeline and methods are open source: github.com/TaylorBurke/forest-sight. This is an independent analysis and not affiliated with any agency.
